# Rejected bag icons

Art that was generated and keyed but is **not wired**, kept here so it is not
regenerated by accident and not silently re-imported by a future pass.

*Currently empty — nothing is rejected.*

## `zysphere-drop.png` — rejected 2026-09-23, **REPLACED the same day**

The first render came back as a Poké Ball: dark upper hemisphere, light lower
hemisphere, equatorial band, circular lens centred on the band. The generation
prompt had asked for the opposite in as many words — *"NOT a Poke Ball: the
seam glows and the halves are offset, asymmetric"* — and the render did not
honour it.

**The replacement landed and is live.** It drops the two-tone hemisphere split
entirely: a uniformly dark faceted orb, layered metallic slat bands rather than
a single equatorial seam, and a Z emblem lens. The two-tone split was the
recognisable part; without it a dark orb with a centre lens reads as its own
object.

The rejected file itself is deleted — keeping a parked duplicate of a filename
that now exists live is a trap for the next import pass. The master of the
original is still in the Creator's `CODEX_DELIVERY_...MAGENTA_72` folder if it
is ever wanted.

### The rule this folder exists to record

**A replacement has to break the SILHOUETTE, not restyle it.** The recognisable
part was the shape — two hemispheres split by a band with a round centre button
— so recolouring or re-rendering the same form lands in the same place. What
works: a housing that is not a sphere; a seam that is off-axis or spirals
rather than ringing the equator; a lens that is offset, multiple, or absent; an
open frame rather than a closed shell. The accepted art took the first of these
by making the whole shell one tone.
