# /game_roster · The Zyraxis Pokedex

Browseable, color-coded, filterable pokedex for every Zyrex in the game.

## Contents

| File | Purpose |
|---|---|
| `index.html` | **Full visual pokedex.** Open in a browser. Filter by tier / type / district, sort by pool / name / tier, click type chips in the legend to isolate. Cards are color-coded by primary type with tier badges, stat bars, moves, and evolution chains. |

## How canon stays locked to game

The Zyrex data used here is generated by merging two authoritative sources:

1. **`/rizers.html` SPECIES** — hand-written species (starters, Elzoran line, wild pool). These are the game's actual live objects.
2. **`/data/codex.js`** — auto-hydrated from `data/aov_game_codex_v11.1.xlsx` sheet `9 MASTER INDEX` via `data/build_codex.py`.

On collision (same species id in both), the hand-written entry wins — matching V2.30's hydration rule (`if (SPECIES[id]) continue; // hand-written wins`).

**Every species base pool = tier × 333** (V2.59 lock). Any row where the pool doesn't equal target shows a ⚠︎ in the tier column of `/GAME_ROSTER.md`, and `python3 data/build_codex.py` prints the same audit at end-of-run.

## Regenerating

After a codex xlsx edit, a `rizers.html` SPECIES change, or an evolution unlink:

```bash
python3 data/build_codex.py     # updates data/codex.json + data/codex.js
python3 tools/regen_game_roster.py    # updates game_roster/roster.json + GAME_ROSTER.md
```

Then reload `index.html` in your browser.

## Design principles

- **No external framework.** `index.html` is a single HTML file with vanilla JS + Google Fonts. Works offline once the fonts load.
- **Type coloring matches the game.** `TYPE_COLORS` constant in `index.html` mirrors the one in `rizers.html` — palette drift is caught by eye.
- **Every card links back to canon.** Card footer shows the id + whether the entry came from `hand` (rizers.html) or `codex` (xlsx).
