Creator request (2026-10-10): "diff the new 1936 roster against codex master roster. add any missing entries. delete none. skip repeats. we will merge entire codex with game soon. humanoids included."

- **Pheonaris / Phoenaris:** Creator ruling 2026-10-10: *Pheonaris* is correct. The Codex row "Phoenaris" is folded into Pheonaris as an alias, and its Codex data is kept on that entry. The Codex sheet still has both rows.
